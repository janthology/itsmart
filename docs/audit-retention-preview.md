# Three-year audit retention — read-only preview proposal

The user selected **three years** for audit retention. `20261101000021_audit_retention_preview.sql` is a local proposal, not approved or deployed. It depends on the separately proposed `00019` structured audit stream. It adds an `occurred_at` index and an active-administrator-only, invoker-security aggregate preview: a single count of proposed audit-stream rows strictly older than three calendar years, using an explicit UTC cutoff. It never returns snapshots, deletes rows, schedules a job, exports data, adds a legal hold, or alters existing retention. Existing `admin_audit_log`, notifications and business history are outside this preview; it is not a complete audit inventory.

UTC and a strict less-than cutoff are technical proposals for review, not a final interpretation of the user's decision.
